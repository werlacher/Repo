Esquisso is loading…

If this message doesn't go away, the app couldn't start.

  1. Open a terminal in the project folder and run npm install (first time only), then npm start.
  2. Keep that terminal open and use the address it prints: http://127.0.0.1:5173.
  3. Don't open index.html by double-clicking it; browsers block the app when it's opened as a file.
